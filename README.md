# Data Jobs Dashboard with powerbi

![Dashboard page 1](/images/dashboard.PNG)

## Introduction

This dashboard was created with the help of **Luke Barousses videos** on data analysis using Powerbi as a guide.The dataset contains *real-world dataset of 2024 data science job posting* It is created for job seekers, job transitioners and job swappers to provide information about the data job market.

## Skills Showcased
- Data transformation(ETL) with power query: Cleaned, transformed, and strucutred raw data using Power Query by handling mising values,  adjusting data types, and adding calulated colums

- Data modelling and analystics: Created custom measure to calculate core KPIs and Metrics including median yearly salary and total job Count.

- Data visualization and layout: Built a user-friendly dashboard incorporating standard charts (Columns, Bars, Line, Area) maps visualization for global distribution, KPI cards and distributed tables.

- Interactive Reporting: Enhanced user naviation using dynamic slicers (filtered by job title), interactive buttons and bookmarks and detailed drill-through views.

## Conclusions 
This dashboard shows how Powerbi can transform raw data into a powerful tool for career analysis. It allows users to slice, filter and drill through data to make informed decisions about their career paths.
